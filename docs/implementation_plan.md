# Implementation Plan - 2026 청주소로초 5학년 체육대회 대시보드

이 프로젝트는 5학년 6개 반의 체육대회 진행을 돕기 위한 반응형 웹 대시보드입니다. 청군(홀수반)과 백군(짝수반)의 경쟁 구도를 시각적으로 극대화하고, 복잡한 경기 규칙과 대진표를 쉽게 관리하는 것에 중점을 둡니다.

## 1. 주요 아키텍처 및 기술 결정
- **Single Page Application (SPA) 구조:** 메뉴 이동 시 새로고침 없이 부드러운 전환 제공.
- **상태 관리 (State Management):** JavaScript 객체로 전체 점수 및 경기 결과를 관리하며, `localStorage`를 사용하여 브라우저 종료 시에도 데이터가 보존되도록 함.
- **디자인 시스템:**
  - **Color Palette:** Blue (#0052D4 - 청군), White/Light Gray (#F8F9FA - 백군), Gold (#FFD700 - 포인트/우승).
  - **Layout:** 상단 내비게이션 바 + 중앙 콘텐츠 영역. 카드 기반 디자인.

## 2. 상세 구현 계획

### 2.1. 데이터 모델 (Data Schema)
```javascript
{
  teams: {
    blue: { name: '청군', classes: [1, 3, 5], totalScore: 0 },
    white: { name: '백군', classes: [2, 4, 6], totalScore: 0 }
  },
  games: {
    dodgeball: { /* 경기 결과 및 라운드 정보 */ },
    plateFlip: { /* 6라운드 결과 */ },
    tugOfWar: { /* 서바이벌 대진 현황 */ },
    relay: { /* 반별 주자 및 순위 */ }
  }
}
```

### 2.2. 모듈별 상세 설계

#### **[MAIN] 종합 대시보드**
- 청군/백군 총점 실시간 점수판 (애니메이션 효과 포함).
- 현재 진행 중인 경기 안내 카드.
- 전체 점수 초기화 기능 (관리자용).

#### **[GAME 1] 피구 (League Dashboard)**
- 1~5라운드 대진 카드 렌더링.
- 각 매치업의 승리 반 선택 시 즉시 100점 가산 logic.
- **내장 타이머 기능:** 7분 카운트다운 타이머.

#### **[GAME 2] 판 뒤집기 (Plate Counter)**
- 라운드별 청군/백군 판 개수(숫자) 입력 폼.
- 점수 계산: (입력된 판 개수) + (승리 팀 보너스 50점).
- 성별 구분 아이콘 표시.

#### **[GAME 3] 줄 다리기 (Survival System)**
- 연승전 대진표 자동 관리.
- 매 경기 승리 시 100점 가산.
- 모든 상대 반 탈락 시 최종 우승 팀 보너스 200점.

#### **[GAME 4] 이어 달리기 (Rank Selector)**
- 반별 순위(1~6위) 선택 드롭다운.
- 순위별 자동 배점 (500, 400, 300, 200, 100, 50).

## 3. 사용자 인터페이스 (UI) 예상 구성
1. **Header:** 대회 타이틀 ("2026 청주소로초 5학년 체육대회") 및 현재 시간.
2. **Nav Bar:** 종합 대시보드 | 피구 | 판 뒤집기 | 줄 다리기 | 이어 달리기.
3. **Main Content:** 각 종목별 대진표, 규칙 안내, 점수 입력 인터페이스.

## 4. 진행 단계
1. **Base Layout & CSS:** 전체 테마 및 레이아웃 구조 잡기.
2. **State Logic:** 점수 합산 및 LocalStorage 연동 기능 구현.
3. **Component Dev:** 각 종목별 특화 UI(대진표, 라운드 카드) 개발.
4. **Polishing:** 애니메이션 추가 및 모바일 반응형 테스트.
