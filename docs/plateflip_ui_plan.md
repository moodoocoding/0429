# 판뒤집기 UX/UI 재설계 개발계획

## 1. 문제 정의
현재 판뒤집기 화면은 기능은 많지만, 한 번에 보여주는 정보가 과다해 사용자가 다음 행동을 판단하기 어렵다.

- 같은 성격의 정보가 여러 블록에 중복 노출됨
- 현재 라운드 입력 영역과 전체 요약 영역의 위계가 불명확함
- 점수 입력, 승패 판단, 보너스 확인이 한 시선 흐름으로 연결되지 않음
- 운영자 입장에서 "지금 뭘 눌러야 하는지"가 즉시 드러나지 않음

## 2. 설계 목표
핵심 목표는 **한 화면에서 한 작업**이다.

- 현재 라운드 점수 입력을 최우선 과업으로 고정
- 전체 라운드 진행 상황은 압축 요약으로만 제공
- 같은 의미의 정보 반복 제거
- 클릭 후 상태 변화를 시각적으로 강하게 피드백

## 3. 사용자 과업 정의
판뒤집기 운영자는 아래 순서로 행동한다.

1. 현재 라운드 확인
2. 청팀/백팀 점수 입력(혹은 +/- 조정)
3. 결과 확인(승/패/동점, 보너스)
4. 다음 라운드로 이동
5. 전체 진행률 점검

따라서 UI도 위 1~5 순서대로 위에서 아래로 배치한다.

## 4. 정보 구조(Information Architecture)
판뒤집기 화면을 4영역으로 분리한다.

1. 상단 운영 바
- 타이머, 현재 라운드, 다음 라운드 버튼
- 기타 정보 제거

2. 현재 라운드 입력 보드 (메인)
- 청팀 카드 / 중앙 결과 / 백팀 카드
- 입력은 숫자 직접 입력 + +/- 동시 지원

3. 라운드 스트립 (네비게이션)
- 1R~6R 칩만 표시
- 각 칩은 `미입력 / 입력완료 / 현재` 상태만 노출

4. 최소 요약
- 누적 점수(청/백), 완료 라운드 수, 현재 보너스만 1줄 요약

## 5. 레이아웃 제안
### 데스크톱
- 1행: 운영 바
- 2행: 현재 라운드 입력 보드(3열)
- 3행: 라운드 스트립
- 4행: 최소 요약

### 모바일
- 운영 바
- 현재 라운드 입력 보드(세로 스택)
- 라운드 스트립(가로 스크롤)
- 최소 요약

## 6. 컴포넌트 명세
### A. 운영 바
- 필드: `현재 라운드`, `타이머`, `시작/정지`, `리셋`, `다음 라운드`
- 원칙: 버튼 3개 이상 군집 시 우선순위 버튼 1개만 강조

### B. 팀 점수 카드(청/백)
- 큰 숫자(현재 라운드 점수)
- 작은 조작 영역(`-`, 직접입력, `+`)
- 상태 라벨은 텍스트 1개만 유지

### C. 중앙 결과 카드
- `청 승리 / 백 승리 / 동점`
- 보너스 규칙: `+50` 표시
- 비율 바는 옵션(필요 시만 유지)

### D. 라운드 스트립
- 칩 텍스트: `1R`, `2R`...
- 상태 컬러
  - 현재: 진한 강조색
  - 완료: 중간 명도
  - 미입력: 저채도

## 7. 시각 규칙
### 위계
- 숫자 > 상태 > 보조설명 순으로 명도/크기 차등
- 카드 내부 텍스트는 최대 2레벨까지만 사용

### 색상
- 청/백 팀 기본색 일관 유지
- 보너스 색은 단일 포인트 컬러(골드 계열)
- `동점`은 중립 회색

### 타이포
- 같은 의미의 텍스트는 동일 폰트/두께 유지
- 선택 전/후 텍스트 박스 높이 고정(레이아웃 점프 방지)

## 8. 상태/인터랙션 설계
### 상태
- `idle`: 미입력
- `editing`: 입력 중
- `finalized`: 라운드 확정

### 인터랙션
- 버튼 클릭 시 즉시 시각 피드백(pressed/active)
- 점수 변경 즉시 결과 카드 업데이트
- 라운드 이동 시 이전 라운드 자동 저장

### 에러 가드
- 음수 입력 차단
- 비정상 큰 값 입력 시 상한 처리 또는 경고

## 9. 제거할 요소(정리 대상)
- 동일 정보의 중복 누적 카드
- 현재 작업과 무관한 보조 설명 문장
- 라운드 정보의 중복 위치 노출
- 의미 없는 장식 배지

## 10. 구현 단계
### 1단계: 구조 정리
- 화면을 운영 바 / 입력 보드 / 라운드 스트립 / 요약으로 재배치
- 기존 중복 컴포넌트 제거

### 2단계: 상태 단순화
- 현재 라운드 단일 소스 상태로 통합
- 라운드별 입력값/결과 계산 로직 분리

### 3단계: 인터랙션 강화
- 선택/입력/확정 시각 피드백 통일
- 키보드 입력/버튼 입력 모두 지원

### 4단계: 반응형/접근성
- 모바일 배치 최적화
- 명확한 포커스 상태, 대비 확보

## 11. 수용 기준(Definition of Done)
- 운영자가 5초 내 현재 라운드와 다음 행동을 판단할 수 있다
- 동일 정보가 두 번 이상 반복되지 않는다
- 점수 변경 시 결과/보너스가 1초 내 반영된다
- 라운드 이동 후에도 컨텍스트 손실이 없다
- 모바일에서 조작 버튼 터치 오작동이 없다

## 12. 빠른 와이어프레임(텍스트)
```text
[판뒤집기 | 3R | 07:00 | 시작/정지 | 다음 라운드]

[청팀 점수 카드]   [결과 카드: 백 승리 +50]   [백팀 점수 카드]

[1R][2R][3R*][4R][5R][6R]

[청 누적 500 | 백 누적 499 | 완료 4/6]
```
