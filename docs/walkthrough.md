# Walkthrough - 2026 청주소로초 체육대회 대시보드

체육대회 운영의 효율성과 재미를 극대화하기 위한 디지털 대시보드 개발이 완료되었습니다.

## 1. 완성된 주요 화면

### 📊 종합 대시보드 (Main)
- 청군과 백군의 점수 차이를 한눈에 볼 수 있는 대형 점수판.
- 현대적인 그라데이션 디자인과 역동적인 레이아웃 적용.

### 🏐 피구 (Dodgeball)
- **타이머 기능:** 7분 카운트다운 기능으로 경기 시간 엄격 관리.
- **리그전 관리:** 1반부터 6반까지 얽힌 복잡한 대진표를 간단한 버튼 클릭으로 기록.

### 🔄 판 뒤집기 (Plate Flip)
- **정밀 기록:** 승/패뿐만 아니라 뒤집은 판의 개수를 숫자로 입력하여 점수 반영.
- **자동 보너스:** 승리 팀 판정 및 보너스 50점 자동 합산 시스템.

### 🤝 줄다리기 (Tug of War)
- **서바이벌 로직:** 승리한 반이 계속 남고 다음 상대가 투입되는 복잡한 연승전 대진을 프로그램이 자동으로 다음 매치업을 계산하여 안내.

### 🏃 이어달리기 (Relay)
- **대역전 포인트:** 최고 500점의 배점을 통해 마지막까지 긴장감을 유지하는 최종 순위 입력창.

## 2. 사용 방법
1.  `index.html` 파일을 브라우저로 엽니다.
2.  왼쪽 메뉴에서 진행할 종목을 선택합니다.
3.  경기가 끝나면 결과를 입력합니다. (점수는 실시간으로 메인 대시보드에 반영됩니다.)
4.  데이터를 초기화하려면 왼쪽 하단의 '데이터 초기화' 버튼을 누르세요.

## 3. 기술적 특징
- **LocalStorage 활용:** 별도의 서버 없이도 모든 경기 기록이 사용자의 컴퓨터에 저장됩니다.
- **반응형 디자인:** 태블릿이나 모바일 기기에서도 원활하게 작동하여 운동장 어디서든 사용 가능합니다.
